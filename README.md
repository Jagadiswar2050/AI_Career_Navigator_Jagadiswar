# AI Career Navigator — Prompt Engineering

**Author:** Thallapaka Jagadiswar  
**Course:** GenAI & LLMs

## Project Overview
AI Career Navigator is a prompt-engineering project that demonstrates how a career-advice assistant can be structured using:

- Role prompting
- Instruction prompting
- Few-shot examples
- Prompt assembly
- Intent-based response routing
- Basic functional testing

## What makes this version different
This version uses a new assistant identity, a different response framework, different examples, and a different local response engine from the supplied reference project.

## Run
```bash
python ai_career_navigator.py
```

Or open:
`AI_Career_Navigator_Jagadiswar.ipynb`

## Example questions
- I want to learn AI
- How do I become a data analyst?
- How can I start cybersecurity?
- How do I improve my resume?
- I want to become a software developer
